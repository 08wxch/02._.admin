## เมนูจัดการ (แถบซ้าย)
| เมนู | ทำอะไร |
| --- | --- |
| รอยืนยัน | ดูสลิป → ดาวน์โหลด → ยืนยัน (ลบไฟล์สลิปออกจาก Storage) / ไม่ผ่าน |
| คอร์สเรียน | เพิ่ม–แก้–ลบ · ไม่จำกัดที่นั่ง · รูปปก · ตัวอย่างที่ผู้ปกครองเห็น |
| บัตรส่วนลด | สุ่มโค้ด · % หรือจำนวนเงิน · ไม่จำกัดครั้ง · เลือกคอร์ส · รูปบัตร · ลบพร้อมไฟล์ |
| ผู้ใช้งาน | กรองตามหน่วยงาน · กดดูรายละเอียดผู้ปกครอง (นักเรียน/โรงเรียน/รหัสผ่าน/ลบบัญชี) |
| ผูกนักเรียน | ทางลัดไปหน้ารายชื่อนักเรียน |
| ตั้งค่า | พร้อมเพย์ + ช่องทางติดต่อ |

## รายชื่อนักเรียน (`#/students`)
- ชื่อนักเรียนเป็นหลัก · ด้านหลังเป็นปุ่มชื่อผู้ปกครองที่ผูกอยู่ (ผูกได้หลายคน)
- กดชื่อนักเรียน → ดูคะแนน/กราฟ/ชุดข้อสอบ + แผงผู้ปกครองด้านขวา (เพิ่ม/ถอด)
- กดชื่อผู้ปกครอง → ข้อมูล + โรงเรียน + รหัสผ่าน + ลบบัญชี (ลบข้อมูลออกจาก Supabase ทั้งหมด)
